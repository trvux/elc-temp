# Inter Variable

`InterVariable.woff2` and `InterVariable-Italic.woff2` are the Inter
typeface (https://rsms.me/inter/), fetched directly from
`https://static.linear.app/fonts/InterVariable.woff2?v=4.1` (2026-09-25) —
the exact file Linear itself serves — to match their rendering byte-for-byte
rather than relying on a same-named build from a different vendor/pipeline
(e.g. Google Fonts or npm font packages), which measurably differ in glyph
metrics despite sharing the "Inter" name.
