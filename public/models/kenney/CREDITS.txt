Files, split into one subfolder per source pack — NOT just for tidiness:
each pack's .glb files reference an external "Textures/colormap.png" by
the same relative path, and every pack's colormap.png is a different
image, so mixing multiple packs' .glb files into one shared Textures/
folder would make one pack's models silently load another pack's texture
atlas.

  commercial/office-tower.glb     <- City Kit Commercial: building-skyscraper-a.glb
  commercial/apartment-tower.glb  <- City Kit Commercial: building-j.glb
  commercial/storefront.glb       <- City Kit Commercial: building-e.glb
  commercial/hospital.glb         <- City Kit Commercial: building-l.glb
  industrial/factory.glb          <- City Kit Industrial: building-k.glb (real sawtooth roof)
  industrial/chimney.glb          <- City Kit Industrial: chimney-large.glb
  modular/townhouse.glb           <- Modular Buildings:   building-sample-tower-a.glb
  modular/serviced-apartment.glb  <- Modular Buildings:   building-sample-tower-b.glb
  modular/villa-house.glb         <- Modular Buildings:   building-sample-house-b.glb
